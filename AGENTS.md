# AGENTS.md

Rust-демон: policy routing трафика с серверного WG/AWG-интерфейса через upstream-VPN (WireGuard, AmneziaWG, Xray TUN) с failover.

## Подход к работе

- Самостоятельно вноси изменения, которые помогают решить задачу и улучшают надёжность, понятность и удобство проекта. Рутинные технические решения не требуют отдельного согласования.
- Изменения должны соответствовать актуальным best practices. Определяй применимые практики самостоятельно с учётом Rust, сетевого демона и устройства проекта; опирайся на официальную документацию и проверенные подходы. При выборе решения отдавай приоритет корректности, безопасности, тестируемости и простоте сопровождения; избегай усложнений без практической пользы.
- Выбирай простое и законченное решение. Рефакторинг, новые зависимости и расширение возможностей допустимы, если их польза оправдывает сложность и сопровождение.
- Сохраняй совместимость конфигурации и поведения, где это возможно. О необходимых несовместимых изменениях сообщай явно и обновляй документацию и примеры.
- Доводи изменения до рабочего состояния: учитывай связанные вызовы, тесты, конфигурацию и документацию.

## Проверки

Выбирай проверки по масштабу и риску изменений. Для правок только документации достаточно проверить содержание и diff. Для существенных изменений кода и перед выпуском используй полный набор:

```bash
cargo fmt --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked
cargo build --locked
python3 tests/regression.py
```

Если проверку выполнить не удалось, укажи причину и что осталось непроверенным.

## Работа с сетью

- Демон требует root и меняет маршрутизацию. Проверяй сетевое поведение в изолированной среде; запуск на хосте с изменением его сети требует явного разрешения пользователя.
- Сценарные тесты подменяют сетевые утилиты во временной директории и работают без sudo. Сохраняй их независимость от сети и привилегий хоста.
- Сейчас проект поддерживает только IPv4 и отклоняет IPv6-подсети. Поддержку можно расширять в рамках задачи, согласованно обновляя валидацию, маршрутизацию, тесты и документацию.

## Стиль

- Следуй принятому в проекте стилю: Rust 2021, tokio; ошибки — `anyhow::Result`, логи — `tracing`. Обрабатывай ожидаемые ошибки без паник.
- Комментарии и документация — на русском, как в остальном проекте.
- Поддерживай форматирование и чистый clippy с `-D warnings`.
